变量与常量

先看一个区别：给名字赋值以后，还能不能重新赋值？

下面用 JavaScript 的 let 与 const 数字示例说明；其他语言的规则可能不同。

同样给值起名字，修改规则不同

本页范围：用 let 声明变量，用 const 声明常量。
对照项 变量Variable 常量Constant
怎么理解这个名字可以改为对应另一个值。这个名字初始化后，不能改为对应另一个值。
重新赋值允许，但不必真的修改。不允许，尝试修改会报错。
常见用途会更新的分数、剩余次数。不需重新赋值的上限、固定配置值。
写法示例let score = 10;const maxScore = 10;

都从 10 开始，试着换成 20

变量：可以重新赋值

let score = 10;
score = 20;

执行后，score 的值是 20。

第二行把新值 20 赋给已有的名字 score。

常量：初始化后不能重赋值

const maxScore = 10;

此时，maxScore 的值是 10。

错误反例：如果接着写这一行——

maxScore = 20;

会抛出 TypeError，这次重新赋值失败；maxScore 仍是 10。

声明
引入一个名字，例如 let score。
初始化
建立它的初始值；let score = 10; 同时完成声明与初始化。
赋值
在这些示例里，= 表示把右边的值赋给左边的名字，不是数学里的“相等”。
重新赋值
给已有的名字再赋一次值，例如 score = 20;。

记住规则，也记住边界

变量不一定会变。用 let 只是允许重新赋值；如果代码没有修改它，它也可以一直保持原值。

JavaScript 的 const 不会冻结对象。它固定的是名字与值之间的绑定。如果值是对象或数组，其中的属性或元素仍可能被修改。

例如，const user = { age: 18 }; 之后，user.age = 19; 是允许的；user = { age: 19 }; 则会报错。前者修改对象内容，后者试图把名字换绑到另一个对象。

读代码时，先问：这个名字是否允许重新赋值？
需要重新赋值，用 let；不需要，优先用 const。

学习范围：JavaScript 入门示例。这里的常量不等于“程序启动前就必须知道的值”。
