结构、外观、交互，
分别由谁负责？

HTML 提供页面结构，CSS 决定外观，JavaScript 可以添加交互行为。先记住这三项分工。

三个术语，放在一起看
英文术语中文理解它负责什么？
HTML 结构Structure 提供页面的内容结构，例如区分标题和段落。
CSS 样式Style 决定页面的颜色、间距和版式，让内容按设定的外观呈现。
JavaScript 行为Behavior可选 在读者与页面交互时，添加所需的额外行为。

交互行为是可选的。如果页面只需要展示文字与样式，可以使用 HTML 和 CSS，不必添加 JavaScript。

放进一个例子：课程介绍页

下面用同一个页面，帮助理解三者的常见用途。

  • HTML：把课程名称设为标题，把课程说明放进段落。
  • CSS：把标题设为深绿色，调整段落之间的距离和整体排版。
  • JavaScript：如果需要，可以在读者点击“切换课程”后，更新页面上的课程介绍。

资料来源：用户提供的三句说明。课程介绍页为辅助理解的教学示例；本页只介绍资料涉及的基础分工。
