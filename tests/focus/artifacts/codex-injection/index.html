HTML / CSS / JavaScript

One web page.
Three jobs.

HTML structures the content. CSS controls its appearance. JavaScript can add responses to what you do.

Imagine a page for a baking class

The same page gives each technology a different job.

HTML Content & structure

Organizes what is on the page: headings, paragraphs, lists, and buttons.

Example: “Beginner baking” is a heading; the class details are a paragraph; “Save event” is a button.

CSS Presentation

Sets how that content looks: colors, fonts, spacing, and layout.

Example: make the heading larger, add space around the details, and give the button a green background.

JavaScript Programmed responses

Can run instructions when someone takes an action, such as clicking a button.

Example: clicking “Save event” could remember the choice and change the button's label to “Saved.”

You may only need HTML and CSS

If the page simply displays the class date, location, and description, it can stay static. JavaScript is optional. This explanation page uses HTML and CSS, with no JavaScript.

Useful roles, with some overlap

This is a starting guide to responsibilities. Browser features work together, and some actions already work without JavaScript—for example, following a normal link to another page.
