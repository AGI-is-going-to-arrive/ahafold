# Introductory material: web page responsibilities

HTML organizes a page into content and structure, such as headings, paragraphs, and buttons.
CSS sets the presentation: colors, fonts, spacing, and layout.
JavaScript can add responses to user actions. A static information page may not need JavaScript.
This is an introductory separation of responsibilities; browser features can work together.
