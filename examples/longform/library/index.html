借到工具，
究竟从哪一步算起？

申请收到了，还不等于留好了一台。工具交回了，也不等于押金已经结清。沿着一次借用，分清每一步改变了什么、还需要满足什么条件。

留置确认锁定一台实物，实际交接才开始借用；服务台登记归还停止逾期计时，检查和押金结清仍是后续动作。理解这四个节点，就能把“成功”消息读到它真正保证的那一步。

这是 material.md 提供的原创虚构教学案例。机构、人员、资产编号、日期与计价单位均不对应实际机构、收费承诺或现实法律规则。全文固定使用 UTC+08:00；“小时”指连续经过的小时，不随设备时区改变。服务时间为每天 09:00–18:00。

00 / 一张路线图

每前进一步，得到的保证都不同

先看可能成功走完的路线，再看各步会在哪里停下。下面的顺序不承诺每份申请都能走到最后。

01 / 分清对象

同一件事，要看三条记录

把“工具现在在哪”“我的申请到哪一步”“我还承担什么借用责任”分别问清，就不会把一个状态套到所有地方。

库存记录看一台实物

每台工具有独立资产号，例如 SHIGUANG-DRILL-CORDLESS-2026-COMMUNITY-NORTH-000184。库存记录说明它在哪里、能否交给下一个人。 L01

  • 待借
  • 已留置
  • 借出
  • 待检查
  • 维修
  • 退役

只有“待借”可以立即分配。同型号的维修工具不能算进可借数量。“总库存三台、可借零台”完全可能：

2 台已经借出
1 台正在维修
0 台立即可借

申请记录看一个请求

它描述某个人的请求进度。留置必须关联具体资产号和领取截止时间；排队没有专属资产，轮到前也没有领取期限。 L02

  • 已收件
  • 排队
  • 已留置
  • 被拒
  • 已取消
  • 已过期
  • 已完成

申请“已完成”表示已经用于交接工具，不能据此认定工具归还了。

借用记录看一次借用

它从实际交接开始，可能依次出现以下状态；按时归还会跳过“已逾期”。 L03

  • 借用中
  • 已逾期
  • 已记归还
  • 已结清

“已记归还”会停止逾期时间增长，但仍可能等待外观检查和押金结算。此时库存为“待检查”，不能立即写成“待借”。

把同一次借用横着看：三条记录不会同步成一个词
发生的事库存记录申请记录借用记录
收到留置确认，尚未领取已留置已留置尚未建立
实际交接完成借出已完成借用中
服务台已登记归还，尚未检查待检查仍为已完成已记归还

表格可在窄屏内横向滚动。三条记录互相引用；表中的“已完成”只属于申请。

02 / 从有资格到有实物

先确认能不能借，再确认有没有一台给你

资格会变，领取当下还要有效 L04

  • 年满十八岁。
  • 会员有效。
  • 没有尚未记归还的逾期借用。
  • 需要安全培训的电钻，领取时培训记录也必须有效。普通测量尺不要求电钻培训。

申请时通过检查，不代表领取时仍然合格。会员到期、出现逾期记录，或需要的培训失效，都可能改变结果。

两种数量限制，数的是不同东西 L05

最多 2 条：未记归还的借用

数的是每人同时持有的借用记录。一旦已经记归还，这条记录就不再属于“未记归还”，即使押金仍在等待结清。

最多 1 份：同类别未结束申请

同一个人对同一工具类别，最多保留一份未结束申请。被拒、已取消、已过期、已完成，都属于申请结束。

留置不占两条借用名额，也不会替你保住一个名额。例如，你先留置电钻，再借满两台其他工具，领取电钻时就会因数量限制无法交接。

读消息时，找的是具体承诺 L06

“申请已收到”

申请已收到，编号 REQ-0412

这只说明请求进入系统。工作人员可能尚未完成资格检查，也可能没有可借工具。自动回执不是已借到或保证能借到的凭证。

“留置确认”

具体资产号
SHIGUANG-DRILL-CORDLESS-2026-COMMUNITY-NORTH-000184
领取地点
确认中列明的具体地点
领取截止时间
确认中列明的具体时刻

这些信息同时列在另发的留置确认中，才说明这台实物暂时不再分配给别人。上方为字段示意，不是有效领取凭证。

最后一台，只能分给一份申请 L07

两个居民可能同时看到页面显示“还有一台”。真正分配时，系统把实物改为已留置和申请改为已留置作为一次不可拆开的操作完成，这叫“原子分配”。

03 / 等待也有边界

留置有倒计时，排队没有到货保证

二十四小时从“留置确认”起算 L08

留置确认只在每天 09:00–18:00 的服务时间内产生。正常领取期限为确认时刻之后的连续 24 小时，不是从申请提交开始，也不是等到下一天打烊。

临时闭馆，不能自行把截止时间往后推 L09

无法提供领取服务时，工作人员必须发出带新截止时间的更正确认，或者取消留置并通知申请人。没有更正确认，就没有自动延期。

迟到后要重新申请，不能跳过队伍恢复原留置。留置的“截止前”也不要与归还混淆：归还允许在到期时刻完成登记。

想取消，要在交接之前办理 L10

取消排队或留置都不收取消费，这时也没有已收取的借用押金。取消留置后，若工具仍处于可交接状况，就立即释放给下一份符合条件的申请。

交接已经发生，就要办理归还。“取消申请”不能抹去正在进行的借用及责任。

队伍按系统记录排，不按谁催得多排 L11

先比较服务器收件时间；同一时刻再比较服务器生成的递增序号。住得近、反复刷新或提前发消息都不会改变顺序。

排队不收押金，也不承诺具体可借日期。前一位可能续借失败；即使准时归还，检查也可能发现工具需要维修。排在前面，不等于能推算哪天拿到。

轮到你时，会重新检查资格 L12

工具释放后，系统按队列次序检查候选人。会员失效、仍有未记归还的逾期借用，或已经借满两台，都可能让这次排队结束。

当前候选人不符合条件

→

申请变为被拒，通知原因
系统继续检查下一人

当前候选人符合条件

→

发出新的留置确认
新的 24 小时从此次确认起算

被拒不是暂停原来的排队位置。资格恢复后可以重新申请，但采用新的收件时间，不继承旧序号。

04 / 真正开始借用

本人交接以后，七天借期才开始

一条确认消息，不能转成代领资格 L13

领取人必须与申请人一致，并出示身份凭证。把确认转发给朋友，不允许朋友代领。

  1. 工作人员再次确认资格、数量，以及所需培训是否有效。
  2. 双方确认工具状况。
  3. 条件满足后，记录实际交接时间，建立借用记录。

领取时不合格，留置申请转为被拒并释放实物。先付押金也不能绕过这些条件。

每次成功借用，押金 100，基础借期七天 L14

每条成功建立的借用记录收取 100 个虚构计价单位的押金。它可以按规则部分或全部退回，不是不可退的会费，也不是工具买断价。

十月三日 16:00 交接

基础到期：十月十日 16:00

若唯一一次续借获批：新到期为十月十七日 16:00

续借只能成功一次，而且不能等到到期那一刻 L15

续借申请必须在到期时刻之前提出，系统处理时也必须尚未到期。处理时还要同时满足：

  • 尚未使用这一次续借机会。
  • 该工具类别没有排队申请。
  • 会员及所需培训仍有效。
  • 没有其他尚未记归还的逾期借用。

获批后，在原到期时刻上增加 7 × 24 小时，总借期最多十四天。不是从提出续借或批准那一刻重新数七天。

只有带新到期时刻的续借确认才改变期限。提出申请、收到收件回执都不算续借成功。即使提前提交，若处理时已经到期，也不符合条件。

有人排队，就不能先批准续借 L16

处理续借时，只要该类别存在排队申请，本次续借即被拒。不能以“排队者之后可能不合格”为理由跳过他们。

两个判断，发生在两个不同事件。续借时看“有没有排队申请”；实际递补时才按顺序检查候选人资格。续借被拒不取消当前借用，只保留原到期时刻。

05 / 时间边界

服务台登记了，才算真的归还

计时终点是实际接收并登记 L17

归还时间以服务台实际接收并登记工具的时间为准。本案例没有无人投递箱。发“我已归还”消息、到达门口、预约检查，都不会停止计时。

服务时间仍为每天 09:00–18:00，要安排在开放时间交回。服务台恰在到期时刻完成登记，属于按时归还，不收逾期费。

同样是“恰好到点”，三种操作的结果不同
操作允许的时间边界恰在截止或到期时刻
领取交接交接时刻 < 留置截止时刻留置已过期，不能交接
提出和处理续借申请、处理时刻都 < 到期时刻不满足续借条件
按时登记归还登记时刻 ≤ 借用到期时刻按时归还，逾期为 0

所以，十月十日 16:00 到期的工具，在 16:00 登记归还是准时；在同一时刻提交续借，却已经太晚。

超过一秒，也算一个逾期日 L18

逾期日数取决于超过到期时刻的连续时间，向上取整。它不是跨过几次午夜，也不是实际使用了几天。

没有超过到期时刻：逾期日数 = 0

已经超过：逾期日数 = 向上取整（连续超时小时 ÷ 24）

“向上取整”就是有剩余也再算一个整日。先算精确超时，再取整，不能先把不足一小时的部分舍去。

06 / 把金额算清

先算逾期费，再区分损伤有没有确认

22.50 封顶的是逾期费这一项 L19

以下金额都使用虚构计价单位。押金是 100；逾期费每天 3.75，逾期费本身最高 22.50。经检查确认有新损伤，额外固定收取 20；没有新损伤或尚未确认时，损伤费为 0。

“尚未确认就不先收损伤费”不等于“这笔押金现在可以直接结清”。如果发生损伤异议，必须暂缓结清，详见损伤复核。

逾期费 = min（3.75 × 逾期日数，22.50）

押金退还额 = max（0，100 − 逾期费 − 损伤费）

min 取较小值，max 取较大值。因此逾期费被限定在 22.50 以内，退款不会小于 0。只适用本文定义的 0–14 个逾期日；损伤异议中的退款需等待复核。

确认的新损伤另算 20，不包含在 22.50 上限里。在已定义区间内，两项合计最高为 42.50，不能把所有扣费理解成最多 22.50。

用整数分计算，最后显示两位小数 L20

系统把 100 记作 10000 分，3.75 记作 375 分，22.50 记作 2250 分，损伤费 20 记作 2000 分。计算全程使用整数分，最后再显示两位小数。

把“两日逾期”逐项拆开

  1. 逾期费：min（375 × 2，2250）= 750 分，即 7.50。
  2. 无新损伤：10000 − 750 = 9250 分，退 92.50。
  3. 已确认新损伤：10000 − 750 − 2000 = 7250 分，退 72.50。

07 / 例外要单独判断

归还事实、损伤责任，不是同一个判断

不同意损伤认定，暂缓的是结清 L21

工作人员应比较交接记录与归还检查，判断是否出现新损伤。申请人不同意损伤认定时，保留证据并人工复核，暂缓这条借用的押金结清。

已经成立的归还事实

已记录的归还时间不撤销，逾期费不继续增长，借用仍是已记归还。

仍待核实的损伤责任

不能把“待核实”先当成固定 20 扣掉。复核结果与实际到账时间，本文都不作保证。

安全故障：先停用，再联系工作人员 L22

借用后发现影响安全的故障，应停止使用并联系工作人员。仅报告故障，不等于工具已经实际交还，也不自动免除全部费用。

是否原有问题
需要比较交接记录，不能仅凭故障报告认定。
是否减免费用
另行人工决定，不能从“已经报告”推断减免结果。
库存显示维修
说明实物的状态，不是对借用者责任的自动判定。

这两类例外都要求把事实分开记录：工具是否已交回、是否出现新损伤、责任如何认定，以及何时可以结清，各有自己的判断依据。

08 / 连起来看

同一台电钻，经过甲、乙、丙

把原文最后的例子展开，就能看到三条记录如何在同一天停在不同位置。这里只描述先后，不替维修或等待承诺具体耗时。

  1. 早上，甲归还电钻

    服务台接收并登记后，甲的逾期计时停止。乙正在排队，但还不能直接获得留置。

    库存：待检查乙的申请：排队甲的借用：已记归还

  2. 检查发现需要维修

    电钻进入维修。总库存里仍有这台电钻，可分配库存却没有增加；维修也不自动裁定甲的损伤责任或结清结果。

    库存：维修乙的申请：仍在排队甲的借用：归还事实不变

  3. 下午，维修通过，出现可分配实物

    工具恢复可分配状况，系统才开始按队列检查候选人。乙此时会员已失效，旧申请被拒，并收到原因。

    库存：待借，可进行分配乙的申请：被拒下一步：检查丙

  4. 丙符合条件，收到留置确认

    实物与丙的申请一起变为已留置。二十四小时从本次确认起算；此刻丙还没有领取。

    库存：已留置丙的申请：已留置丙的借用：尚未建立

现在，别人不能再分到这台电钻，但丙的七天借期还没有开始。乙若恢复会员并重申，使用新的收件时间。甲的押金何时结清，仍取决于甲自己的检查与结算进度。

如果丙随后在截止前本人领取、再次通过检查并完成交接，库存才变为借出，丙的申请变为已完成，丙的借用记录才开始。这里是按规则延伸的条件分支，不是说原文已经记载丙实际领走了工具。

09 / 费用之外的后果

“钱交过了”，还不足以判断接下来怎么做

一百押金不能全部叫作沉没成本 L23

“沉没成本”说的是已经无法改变、无法追回的过去支出。但这里的押金会因归还情况部分或全部退回，所以已经交出去，不等于已经全部失去。

已经不能改变的支出

讨论它时，看它是否确实已经不可追回。不能仅凭付款发生在过去，就把整个押金归到这一边。

接下来仍可追回的钱

例如，逾期两日、无新损伤时，按已定义规则可退 92.50。归还、检查与结清会影响这笔钱如何处理。

同时还要考虑归还所需的时间、交通，以及继续占用工具的责任。金额是判断的一部分，不能替代这些条件。

第六个逾期日起费用封顶，归还仍会改变状态 L24

在本文定义的零至十四个逾期日内，第六日已达到逾期费上限。此后继续拖延不再增加逾期费，但不表示工具已经买断，也不表示归还没有意义。

  1. 结束占用。服务台登记归还后，这条借用不再是未记归还。
  2. 启动检查和可退押金的结清。发生损伤异议时，结清仍需等待人工复核。
  3. 让社区有机会再次使用。能否重新分配取决于检查后的实物状态；维修、退役工具不会因为归还就立即变成待借。

这些是案例中的状态后果。它们不承诺现实投资回报，也不构成给读者的具体财务决定建议。超过十四个逾期日的处置，仍然属于本文未定义的范围。

下次看到“成功”，对照这四件事

申请人
是否收到列明资产号、地点、截止时间的留置确认？单有收件编号不够。
排队者
看服务器顺序与当前资格；排队没有专属实物，也没有具体到货承诺。
借用者
看交接后的准确到期时刻；只有带新到期时刻的续借确认能改变它。
办理归还的人
看服务台是否已经登记归还，再分别看检查、损伤责任和押金结清。
