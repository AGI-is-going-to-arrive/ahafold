and callbacks to separate a booking's actual state from the client's evidence.

唯一来源为虚构的[16 条协议](../../../tests/longform/inputs/retries.md)。

The default is unchanged Codex output. Grok received English material and an
English prompt without an explicit “Write in English” clause, then produced Chinese.
Its reviewed variant preserves Chinese and content, with CSS fixes for print and
the default numeric example without JavaScript. Both runs used **0 image calls**;
Fold was not needed. Specify the desired output language when requesting your guide.

两次生成均为 **0 次图片调用**，未使用小折。请求作品时请明确成品语言。
