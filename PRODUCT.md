# AhaFold

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

A single installable agent skill. Output is local HTML with embedded CSS, optional SVG and small JavaScript interactions. The reader needs only a browser; development checks are separate from the installed skill.

## Users and purpose

An author asks their existing agent harness to explain a concept or supplied material, including substantial multi-section documents. A reader can take the short answer, navigate a relationship overview, and inspect the reasoning, precise details, exceptions and sources at their own depth.

## Capabilities and constraints

Plan original illustrations and accurate HTML together by default, for both compact explanations and long guides. Begin with a cognitive anchor scene and add a chapter scene only when it explains a different relationship. Use the current harness's native image tool; images carry actions, situations and a few short labels, while HTML/SVG carries prose, code, formulas and precise diagrams. Explicit no-image requests, text-only revisions and precision-only material remain valid exceptions. Fold and interaction are used when they help. v0.1 has no database, indexer, service, shared model SDK, or cross-harness fallback.

Windows, macOS, and Linux are targets, with Codex, Grok Build, and Antigravity CLI as host targets. Compatibility claims require actual installation-to-output evidence. Keep original generated bytes and provider markings. Ordinary reading and interaction work offline and do not call a model.

## Brand commitments

The product is AhaFold; the skill ID is `ahafold`. The character is Fold / 小折, an original apricot paper page with one teal folded corner and two short dark eyes. Its reference sheet is packaged in `skills/ahafold/assets/fold/reference-sheet.png`. The Chinese tagline is “把复杂，展开讲。” The English subtitle is “Turn complex ideas into illustrated explanations.”

## Accessibility and evidence

Pages must remain readable at desktop 1440 px and mobile 390 px, with keyboard operation, visible focus, useful image alternatives and captions. The starter template is an editable resource, not a generated-image example or evidence of host compatibility. Development records and examples carry their own verified status.

Long guides additionally cover 320/768px, native contents/deep links, print,
no-JavaScript reading and actual 200% browser zoom. AhaFold's internal 12px minimum
for rendered diagram labels complements accessibility checks; it is not described
as a WCAG minimum-font requirement. Long-form scope was explicitly added during
development; it remains the same skill and does not add a repository-analysis product.
