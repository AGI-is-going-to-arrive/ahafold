AhaFold

把复杂，展开讲。

图像建立直觉，
文字讲清关系。

一页解释里，动作与情境可以交给插画；准确的定义、数字和推理留在可编辑的文字与图形里。两者围绕同一个问题展开。

这是 AhaFold 的可编辑 HTML 模板。本页以“图文分工”说明阅读结构，没有生成插画，也不是成品示例或宿主验收记录。

先找到要解释的关系

从读者卡住的地方开始：他们分不清两个概念，还是不明白一个结果怎样发生？把最重要的关系写成一句话，再决定怎样呈现它。

例如，本页要说明的是：画面与文字可以分工，却不能讲出相互矛盾的含义。这个共同含义决定了图里该出现什么动作，也决定了正文必须补足什么。

先确定要让读者看懂什么，再选择能把这件事讲清楚的表达。

让图与文字各自承担任务

需要画面时

用一个清楚的动作、情境或对照建立直觉。小折可以参与这个动作；若角色无助于解释，就省略它。

图内可放少量必要短标签。重要标签的含义也应出现在可读、可搜索的图注或正文中。

需要准确时

把长正文、代码、公式、精确数值和复杂图表留在 HTML / SVG 中。读者可以核对细节，作者也能直接修改它们。

只修改正文或语言时，保留含义没有变化的原图。修改位图内部的字，可能需要重新编辑或生成那张图。

把直觉的边界也讲出来

类比只突出一部分关系。交付前要说明：画面中哪一部分对应真实概念，哪一部分只是帮助理解的简化。必要的限制应直接可见，不能只藏在展开区里。

本页的分工图是一条编辑建议，不是关于学习效果的实验结论。它也不表示图片一定比文字好。

没有插画，也可以是一页好解释吗？

可以。术语对照、准确的公式推导，或本来就很清楚的简短说明，可能只需要文字与简单图形。

同样，交互应当帮助读者观察一个变化或检查自己的理解。没有这种用途时，静态页面已经足够。

来源与说明

本页内容是 AhaFold 的编辑约定，没有引用外部研究。正式作品在这里注明使用的资料、已核验的来源，以及无法核验的部分。若仅依据用户提供的材料，也应说明材料范围。

替换模板内容时，同步检查标题、语言、图注、SVG 标签和展开区。读者即使不联网，也应能读懂正文；来源链接可以在有网络时再打开。

这份模板可直接在浏览器里离线打开。文字与 SVG 均可编辑；阅读和展开内容不调用模型。
